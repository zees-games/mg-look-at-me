# Sounds

Every file here is CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/). `tools/make_sounds.py` writes all of them: it synthesises the first seven and copies the rest from Kenney's bundle, and normalises every file to a -2 dBFS peak.
